## 📅 Daily Schedule

### Weekdays (2 hours)
| Time | Task |
|------|------|
| 30 min | Learn concept + watch/read |
| 60 min | Solve problems (attempt first!) |
| 20 min | Re-solve without help |
| 10 min | Explain solution aloud |

### Weekends (3–4 hours)
| Time | Task |
|------|------|
| 1 hr | Concept review |
| 2 hr | Problem practice |
| 1 hr | Mock interview / revision |

---

## 🚨 Golden Rule

> ❌ **NEVER**: Watch solution → copy code → mark done  
> ✅ **ALWAYS**: Attempt → Struggle → Identify pattern → Solve → Explain → Re-solve
